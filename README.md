# MusicFlow

Персональная музыкальная библиотека для macOS: проекты, задачи, заметки, теги, подборки, аудиопревью, связь с DAW, архив и резервные копии. Один проект — один трек. Интерфейс на русском, работа полностью локальная. Текущая версия — **0.2.0**.

## Запуск

Откройте **`dist/MusicFlow.app`** двойным щелчком в Finder. Приложение можно перенести в папку «Программы»: база хранится отдельно, поэтому перенос и обновление приложения не удаляют проекты. Python, Node.js и терминал для использования готовой сборки не нужны.

Первая версия собрана для Apple Silicon и проверяется на текущем MacBook. Это персональная сборка; публикация в App Store и нотариальное заверение Apple не входят в MVP.

## Работа с проектами

1. Нажмите «Новый проект» и введите название. BPM, тональность и жанр необязательны.
2. Выберите трек в списке. В карточке доступны параметры, папка и заметки. Для этих полей нажимайте «Сохранить».
3. Добавляйте задачи вручную или кнопкой «Добавить типовые задачи». Изменения задач сохраняются сразу. Стрелки меняют порядок; кнопка карандаша переименовывает задачу.
4. Стадия выбирается вручную и не зависит от выполненных задач. Процент показывает только выполнение чек-листа.
5. Выбирайте существующую папку через системный диалог и сохраните карточку. «В Finder» открывает сохранённую папку. MusicFlow не копирует и не удаляет музыкальные файлы.
6. Архивируйте отложенные проекты; вернуть их можно в разделе «Архив». Постоянное удаление проекта также удаляет задачи и заметки.

Горячие клавиши: **⌘N** — новый проект, **⌘F** — поиск. В диалогах работают Tab и Escape; в переименовании задачи Enter сохраняет, Escape отменяет.

## Новое в 0.2.0

- **Основной проект DAW:** в карточке выберите `.flp` или файл другой DAW и сохраните. Кнопка «В FL Studio» открывает связанный FLP в установленной FL Studio. Для других поддерживаемых проектов используется приложение, назначенное в macOS. Если папка ещё не выбрана, MusicFlow подставит папку этого файла.
- **Демка:** при открытии карточки MusicFlow ищет WAV, MP3, M4A, AIFF, FLAC и AAC внутри связанной папки, включая подпапки. В приоритете названия `demo`, «демо», «демка», `preview`, `rough`, `bounce`, `mixdown`, папки экспортов и имя основного проекта. Внутри одного приоритета выбирается свежий файл. Остальные найденные аудиофайлы доступны в списке; одиночные сэмплы не назначаются демкой автоматически.
- **Плеер:** прослушивание, пауза, перемотка и громкость доступны прямо в карточке. Экспорт из DAW нужно сделать самостоятельно: MusicFlow воспроизводит готовые аудиофайлы и не рендерит `.flp`. «Выбрать другой аудиофайл» позволяет указать демку в другом месте. Ручной выбор сохраняется; пункт «Автоматически» возвращает автопоиск.
- **Обновление файлов:** папки проверяются при запуске приложения, при открытии карточки и каждые 20 секунд, пока карточка открыта. Кнопки обновления позволяют проверить их сразу. Сканирование идёт в фоне, не изменяет файлы и не следует по символическим ссылкам. При слишком большой папке или недоступных файлах размер помечается как частичный. Плеер показывает ошибку, если аудио перемещено или его кодек не поддерживается WebView.
- **Последняя работа:** дата берётся из изменения основного файла DAW, либо из свежего файла DAW в папке, когда основной не выбран. Правка заметок и задач её не меняет. Размер — сумма логических размеров файлов в папке; он может отличаться от фактически занятого места на APFS. В списке есть сортировка по размеру и последней работе.
- **Теги:** вводите тег и нажимайте Enter или `+`. Их можно удалять и использовать как фильтр. Названия без учёта регистра не дублируются.
- **Подборки:** кнопка `+` рядом с разделом «Подборки» открывает создание, переименование и удаление. Участие трека задаётся флажками в карточке; один трек может входить в несколько подборок. Удаление подборки сохраняет треки и файлы.

При обновлении база первой версии автоматически дополняется новыми полями. Перед миграцией сохраняется защитная копия. Резервные копии версии 0.1.0 можно восстановить в 0.2.0; обратное восстановление копии 0.2.0 в старое приложение не поддерживается.

## Резервные копии

«Настройки» → «Сохранить резервную копию» создаёт файл `.sqlite3` в выбранном месте. В нём сохранённые проекты, задачи, заметки, теги, подборки и ссылки на папки, DAW-файлы и демки; сами аудио и DAW-файлы копируйте отдельно.

Восстановление заменяет библиотеку целиком, а не объединяет её с текущей. Приложение проверяет целостность, структуру и версию копии, запрашивает подтверждение и сохраняет текущую базу перед заменой. Повреждённые и несовместимые копии отклоняются. При переносе на другой Mac может потребоваться заново выбрать папки проектов.

Пользовательские данные:

- `~/Library/Application Support/MusicFlow/musicflow.sqlite3` — библиотека;
- `~/Library/Application Support/MusicFlow/backups/` — защитные копии перед восстановлением и миграциями;
- `~/Library/Application Support/MusicFlow/musicflow.log` — журнал ошибок.

## Разработка и сборка

Нужны отдельный Python 3.12 и Node.js 22+; системный Python macOS использовать не следует. Все команды выполняются из корня проекта.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
cd frontend
npm ci
cd ..
bash scripts/dev.sh
```

Сборка самостоятельного приложения:

```sh
bash scripts/build.sh
```

React/TypeScript/Vite → FastAPI/Uvicorn → SQLAlchemy/SQLite. Изменения структуры БД ведутся через Alembic. pywebview использует Cocoa/WKWebView; py2app включает runtime Python и зависимости в `.app`. В `setup.py` предусмотрена совместимость py2app 0.28 с CPython, где zlib встроен в интерпретатор.

Backend слушает только `127.0.0.1` на свободном порту. Каждый API-запрос требует токен запуска; диалоги Mac доступны через ограниченный мост pywebview. При выходе локальный сервер завершается. Одновременно допускается одна копия приложения на одну базу.

Для тестирования на отдельной базе используйте переменную `MUSICFLOW_DATA_DIR`, указывающую на тестовую папку. Рабочие данные пользователя не используются в автоматических тестах.

```sh
.venv/bin/python -m pytest -q
cd frontend
npm run build
npm test
```
