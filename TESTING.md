# Проверка MusicFlow

## Версия 0.3.0

- Backend: **37 тестов прошли**, React: **13 тестов прошли**. TypeScript и production-сборка Vite завершились успешно.
- Новые проверки охватывают журнал реальных изменений, отсутствие событий для одинаковых значений, выполнение и повторное выполнение задач, неизменяемость автоматических событий и каскадное удаление журнала с проектом.
- Для ручных записей проверены создание, изменение, удаление, изоляция проектов, положительная длительность, отклонение будущих дат и отсутствие часового пояса. Запись 31 декабря в часовом поясе UTC−3 попадает в 1 января UTC; верхняя граница периода исключается.
- Проверены исходное состояние файлов без выдуманной истории, обнаружение изменений DAW и демки, повторные сканирования, перезапуск сканера и исчезновение файла. Исходное состояние сохраняется при сохранении одинаковых параметров.
- Проверены экспорт/восстановление истории, отклонение повреждённого события и восстановление копии 0.2.0 с сохранением полей и без генерации прошлых событий; исходный файл копии не изменяется. Проверки старой версии 0.1.0 также проходят.
- React-проверки подтверждают полный экран проекта, скрытие списка, возврат к тому же поиску и позиции прокрутки, сохранение черновика при переключении вкладок, выбор дней/месяцев, защиту незавершённой записи, сохранение длительности, редактирование и подтверждение удаления.
- В самостоятельной `.app` на тестовой базе `.cache/v03-qa/data/` визуально проверены обзор, задачи, календарь, широкий экран и окно около 960 pt. Через интерфейс выбрано 11 октября, создана запись на кириллице с длительностью 25 минут; она появилась в выбранном дне. Выполнение задачи «Записать вокал» изменило прогресс на 50% и добавило событие в сегодняшний журнал.

- Итоговая сборка открыла пользовательскую библиотеку. После миграции 0002 → 0003 все исходные поля проекта, 4 задачи, подборка и её связь совпали с сохранённым состоянием до обновления. Создана защитная копия; прежние события не генерировались. Проверены подпись `.app` и версия 0.3.0 в ZIP-сборке.

## Версия 0.2.0

Проверки выполнены на macOS 26.5.1, Apple Silicon. Новые сценарии проверялись на отдельной базе `.cache/v02-qa/data/`.

- Backend: **32 теста прошли**. Frontend: **9 тестов прошли**. TypeScript и production-сборка Vite завершились успешно.
- Проверены теги без дубликатов, фильтры, участие в нескольких подборках, создание и удаление подборок без удаления проектов.
- Проверены фоновый расчёт размера, дата сохранения DAW, автоматический выбор демки, закрепление ручного выбора, отсутствующие папки и исключение символических ссылок. Отсутствующий основной DAW-файл не подменяется датой другого файла.
- Проверены защита аудиозапросов, выдача только выбранного файла, byte-range для перемотки, недопустимые диапазоны и исчезновение аудиофайла.
- Проверены миграция базы 0.1.0, восстановление старой копии без изменения её источника и сохранение новых полей в копии 0.2.0.
- В итоговом `.app` автоматически найдена WAV-демка в папке с кириллицей и пробелами. Подтверждены длительность 10 секунд, воспроизведение до конца, перемотка, повторное воспроизведение с выбранной позиции и изменение громкости до 50%. Визуально проверены плеер, карточка и окно подборок; через интерфейс создана тестовая подборка на кириллице.
- Открытие DAW проверено тестом системной команды с безопасной передачей пути и bundle ID установленной FL Studio. Реальный проект пользователя в DAW во время проверки не открывался.
- Тестовое приложение завершилось с кодом 0. Итоговая сборка открыла рабочую библиотеку и показала проект «Редкость». После миграции с 0001 на 0002 все исходные поля проекта совпали по SHA-256 с состоянием до обновления; сохранились 1 проект и 0 задач. Создана защитная копия перед миграцией.
- `codesign --verify --deep --strict dist/MusicFlow.app` завершилась успешно.

Сжатие папок проектов не добавлялось. Аудиофайлы читаются с диска; рендеринг из DAW и копирование музыкальных файлов не выполняются.

## Версия 0.1.0

Платформа: macOS 26.5.1, Apple Silicon (arm64). Проверки приложения выполнялись на отдельной базе `.cache/native-qa/`. Пользовательская библиотека не заполнялась тестовыми треками.

## Автоматические проверки

- `python -m pytest -q`: 24 проверки API, SQLite, резервных копий и системного моста.
- `npm test`: 5 проверок взаимодействия React в jsdom.
- `npm run build`: проверка типов TypeScript и production-сборка Vite.

Покрыты создание, изменение, поиск на кириллице, фильтры, сортировка, архив и удаление; чек-лист, шаблон без дубликатов, порядок и прогресс задач; сохранение при повторном открытии базы, каскадное удаление и изоляция задач разных проектов; отклонение неавторизованных запросов и конкурентные операции.

Для копий проверены экспорт и восстановление, сохранение предыдущей базы, повреждённые файлы, неподдерживаемая версия, нарушенные связи, посторонние триггеры и структура, некорректные стадии, изменение файла после его выбора. Отдельные проверки подтверждают отмену системных диалогов, пути с кириллицей и пробелами, открытие папки без shell-интерполяции и различия строкового/кортежного ответа Cocoa.

React-проверки охватывают создание из пустого состояния, защиту несохранённых изменений, изменение стадии независимо от задач, сочетание поиска и фильтра, отмену копирования и сохранение введённого текста после ошибки записи.

## Проверки в приложении на Mac

- Открыты самостоятельные сборки `.app`; проверены пустая библиотека, создание проекта, типовые задачи и отметки выполнения.
- Итоговый `dist/MusicFlow.app` запущен двойным щелчком в Finder без терминала. На рабочей базе показана пустая библиотека.
- После перезапуска проект и задачи сохранились.
- Перенесённая копия приложения открыла ту же тестовую библиотеку; запуск выполнялся с `PATH=/usr/bin:/bin`, без Python и Node.js в PATH.
- Через системный диалог выбрана папка с кириллицей и пробелами; привязка сохранена, папка открылась в Finder.
- Проверены предупреждение при выходе с несохранёнными изменениями, отмена выхода и нормальный выход после сохранения. Тестовый процесс завершился с кодом 0.
- Через настройки экспортирована SQLite-копия, затем выполнено восстановление с подтверждением. Интерфейс показал восстановленную библиотеку; создана защитная копия предыдущей базы.
- Визуально проверены широкий список и карточка справа, а также окно шириной около 960 pt с карточкой в виде отдельного экрана.
- Проверяется подпись пакета командой `codesign --verify --deep --strict`.

При проверках устранены проблемы упаковки динамического backend AnyIO, встроенного zlib в CPython, блокировки Cocoa при выходе, возврата фокуса после системных диалогов и строкового результата NSSavePanel.

## Границы проверки

Проверена работа на этом MacBook. Совместимость с другими версиями macOS и Intel Mac, App Store, нотариальное заверение Apple и облачная синхронизация не входят в эту сборку. Интерфейс и API используют локальные ресурсы; сетевые настройки Mac для тестирования не изменялись.
